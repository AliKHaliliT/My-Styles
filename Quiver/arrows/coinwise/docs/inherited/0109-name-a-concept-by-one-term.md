# 0109. Name a concept by one term

Status: Accepted
Date: 2026-10-15

## Context

The gate's ubiquitous-language item holds that a new name in code
uses the vocabulary the tree already speaks, and the prose law said
nothing of the same drift in prose, where a writer taught to vary the
word reaches for a synonym and a reader meets a second thing. A
writing method and a review method the owner keeps outside the family
both carry the rule in one line, one term per concept and no synonyms
for variety, with a style sheet that fixes the term.

## Options considered

- A style sheet per project. Refused, because the rulebook, the map
  and the invariants ledger already fix the names a project speaks,
  and a fourth list would drift from the three.
- Leaving it to the portability test. Refused, because a sentence
  with a synonym passes the test and still names two things.

## Decision

One term names one concept across a document, the term that named
the thing first naming it everywhere, because a synonym brought in
for variety is read as a second thing. The sentence stands in the
rulebook's Prose section, one text across the family, held in review,
because no tool can tell a synonym from a distinction.

## Consequences

A reader who meets a second word for a thing can trust it is a second
thing.
