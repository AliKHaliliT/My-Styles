# Bibliography

Every work this inquiry consulted, as self-contained citations addressed by
key. A citation names the edition or dated version actually used and survives
the death of any locator riding on it. Prose cites keys, never bare links, and
this file is the one place an external locator may appear.

- **goldberg1991**: Goldberg, David. 1991. "What Every Computer Scientist
  Should Know About Floating-Point Arithmetic." ACM Computing Surveys, volume
  23, number 1, pages 5 to 48. Read for why error compounds under repeated
  rounding and accumulation.
- **ieee754-2019**: IEEE. 2019. IEEE Standard for Floating-Point Arithmetic.
  IEEE Std 754-2019, revision of IEEE 754-2008. Read for the definition of the
  roundTiesToEven attribute and its selection as the default rounding
  direction.
- **fowler2002**: Fowler, Martin. 2002. Patterns of Enterprise Application
  Architecture. Addison-Wesley, first edition. Read for the Money pattern and
  its treatment of rounding as an explicit design decision.
