# Bibliography

Every work this inquiry consulted, as self-contained citations addressed by
key. A citation names the edition or dated version actually used and survives
the death of any locator riding on it. Prose cites keys, never bare links, and
this file is the one place an external locator may appear.

- **goldberg1991**: Goldberg, David. 1991. "What Every Computer Scientist
  Should Know About Floating-Point Arithmetic." ACM Computing Surveys, volume
  23, number 1, pages 5 to 48. Read for why error compounds under repeated
  rounding and accumulation.
- **ieee754-2019**: IEEE. 2019. IEEE Standard for Floating-Point Arithmetic.
  IEEE Std 754-2019, revision of IEEE 754-2008. Read for the definition of the
  roundTiesToEven attribute and its selection as the default rounding
  direction.
- **fowler2002**: Fowler, Martin. 2002. Patterns of Enterprise Application
  Architecture. Addison-Wesley, first edition. Read for the Money pattern and
  its treatment of rounding as an explicit design decision.
- **psf2026**: Python Software Foundation. 2026. "decimal, Decimal
  fixed-point and floating-point arithmetic." The Python Standard Library
  documentation for Python 3.14.7, as published at docs.python.org and read
  on 2026-09-29. Read for the rounding mode of the default context and the
  definitions of the two half modes.
- **oracle2023**: Oracle. 2023. "Class RoundingMode." Java SE 21 and JDK 21
  API Specification, package java.math, as published at docs.oracle.com and
  read on 2026-09-29. Read for the definitions of HALF_UP and HALF_EVEN and
  the notes beside them.
- **ecma402-2026**: Ecma International. 2026. ECMAScript Internationalization
  API Specification, ECMA-402, the living draft of the 2027 edition as read on
  2026-09-29. Read for the default rounding mode of the number formatter.
- **irs2025**: Internal Revenue Service. 2025. "Instructions for Form 1040
  (2025)." As published at irs.gov and read on 2026-09-29. Read for the rule
  on rounding to whole dollars and on adding amounts before rounding.
