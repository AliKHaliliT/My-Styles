# 0004. Let evidence be read as well as run

Status: Accepted
Date: 2026-08-27

## Context

The rulebook's Evidence bullet described one kind of evidence, what ran, in
which arrow, at which pinned commit. That letter quietly made code a
prerequisite for settling a claim, though nothing else in the law agrees with
it. Every arrow-touching rule is conditional on arrows existing, the audit
builds its arrow set with an existence check, and the seat descends from a
study of research methodology in which most families are not computational at
all. The question of whether an instance may be pure research, no code, was
asked directly, and the honest answer was that the spirit says yes while the
Evidence sentence had no home for it.

## Evidence

A minimal instance was assembled with no arrows directory and a single claim
whose evidence quotes a source's tabulated numbers and cites its bibliography
key, then run through the real audit. The result was zero problems and zero
advice, including the citation resolving against the bibliography, so the
mechanical layer already treats read evidence as legal and only the rulebook's
letter lagged.

## Decision

The Evidence bullet gains one sentence. Evidence gathered by reading rather
than running quotes the source's numbers or words in full and cites its
bibliography key, and it carries no pin, since no tree produced it.

Both evidence kinds live under the same discipline, quoted in full and never
pointed at. The difference is only what anchors them: a run is anchored by a
pin to the commit whose tree produced it, and a reading is anchored by a
bibliography entry that names its edition.

## Consequences

A codeless inquiry is first-class rather than tolerated, so someone can
instantiate the seat for pure literature work with the full spine, question,
conjectures, claims, graveyard, and bibliography, and nothing goes unused
except machinery that was conditional anyway.

What a codeless instance gives up is staleness detection, which is defined by
an arrow moving past a pin. The literature analogue, a cited source gaining a
new edition, has no advisory and stays a person's job, which is why the
bibliography rules force editions to be named. No check changes, because the
proof above showed none needed to.
