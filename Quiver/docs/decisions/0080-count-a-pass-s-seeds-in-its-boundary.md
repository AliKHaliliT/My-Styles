# 0080. Count a pass's seeds in its boundary

Status: Accepted
Date: 2026-10-15

## Context

A pass measures its search by its funnel, retrieved, screened, entered
and read in full, and the completeness review looks afterward for what
enumeration missed. Neither tests a search string before the pass
relies on it. The pass of 2026-09-30 ran one string in one index and
examined sixty records of 460; what the string failed to return nobody
can say, because nothing was known to be owed before it ran. A review
method the owner keeps outside the family fixes a set of works known to
be relevant before any search, tests every string against them, and
treats a missed work as a wrong string to fix and re-run.

## Options considered

- A recall figure, found over indexed as a percentage held to a floor.
  Refused, because a figure standing in for a judgment is the score the
  family carries none of, and eighty percent of five seeds says nothing
  a reader can weigh.
- The completeness review alone. Refused, because it checks what
  enumeration produced and never the instrument that produced it, and
  it runs after the strings have already shaped the corpus.
- Seeds on every pass. Refused, because a scoping read over works
  chosen by hand and a snowball from them run no string to test, and a
  rule that cannot be met honestly is met dishonestly.

## Decision

The Boundary of a pass carries a seeds line before its funnel. It names
the works the pass fixed as relevant before any string ran, from the
question's decomposition, an earlier pass, a review's reference list or
the owner and never from the string they test, and counts them as
fixed, as indexed where the searched indexes hold them, and as found
where the strings returned them, the numbers never rising; an indexed
seed the strings missed is named with the word the string lacked and
the corrected string as a new run. A seed is a relevant work, so the
pass enters it and Found names it whatever the strings did. A pass that
ran no string writes `Seeds: none`. The audit holds the line's presence
on every pass added from the rule's arrival, the numbers never rising,
the key count against the fixed count and every seed among the keys
Found names; whether the seeds were fixed before the strings and found
apart from them stays with review. The rule took the form of a check
over the record's shape, because no stronger form reaches a judgment
made before a search.

## Consequences

A search is measured by what it was known to owe rather than by what it
happened to return, and a later pass over a slice tests its strings
against the works the inquiry already holds. The three passes in the
tree stand without the line, since a record admits no edit.
