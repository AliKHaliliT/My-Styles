# 0064. Let a classifying pass write its Found as a table

Status: Accepted
Date: 2026-09-30

## Context

A mapping pass over a fragmented field produces a classification, every
work placed against a few facets, the crop model in the loop, the number
of agents, whether the code was released, and that table is the pass's
finding. The Found section held one key per line with its depth and no
room for a facet, and the rule that what a pass finds lives in the ledger,
the bibliography, the claims and the decomposition, and nowhere else, read
as if the table had no home. That rule targets a synthesis, which repeats
what the ledger holds and rots beside it. A classification repeats
nothing; it is data the ledger does not hold.

## Evidence

Checked on 2026-09-29 against the audit. The citation check reads every
key in a record after blanking code spans only, so a key in a table cell
already resolves like a key in prose, and the form rule of record 0037,
Choose the form by the shape of the information, puts like items that
share attributes in a table, one row each. Nothing but the depth check's
line pattern stood between a mapping pass and its table.

## Options considered

- A living document for the classification. Refused, because a document
  rewritten in place beside the ledger is the synthesis the rule refuses,
  and a classification is a dated snapshot that a later pass extends.
- One claim per row. Refused, since a facet is not an assertion with
  evidence and threats; the table is data and a claim is knowledge.
- Widening Found to a table whose first two cells the audit already reads.
  Adopted.

## Decision

Found may be one table whose first two cells are the key and its depth and
whose further columns are the facets of the classification, one row per
work, beside the list form for a pass that classified nothing. The audit
reads a depth from a list line or a table row alike and holds the same
shape over both, and the selftest plants a table with its depth and one
without. A later pass over the slice re-issues the table whole with its
additions, because a record is not edited, and the chapter's table is
written from the latest pass. The rulebook's Found bullet and the guide's
pass section carry the rule.

## Consequences

A mapping pass has a home for its finding that is dated and immutable, and
the reader of a claim resting on a classified work still finds its depth
where every other depth stands. The demo has no mapping pass, so the
table's worked instance is the selftest's plant until one runs, and the
list form stays the exemplar.
