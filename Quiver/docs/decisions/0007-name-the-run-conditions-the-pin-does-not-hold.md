# 0007. Name the run conditions the pin does not hold

Status: Accepted
Date: 2026-08-28

## Context

A claim's pin promises that the evidence can be reproduced because the tree
holds everything that produced it. For the demo arrow the promise is whole,
since the grid, the arithmetic, and even the interpreter version are pinned
bytes. The promise quietly breaks the first time an experiment's outcome
depends on something no commit hash reaches. The obvious case for a research
seat in this era is a model behind an API, where the same pinned prompt
returns different numbers after a provider ships a new version, and the
record cannot say why. The subtler case is contamination, and it was
observed stated sharply in the evaluation harness of the public repository
ayghri/i-have-adhd. An operator's own configuration can inject the very
behavior under test into every run, including the control runs, so the
baseline is already running the candidate and the comparison measures the
thing against itself.

## Decision

Two sentences join the Evidence rule. A run whose outcome depends on
conditions the pinned tree does not control, such as the model behind an
API, a provider's version, or a metered budget, names those conditions in
the record, because a pin reproduces only what the tree holds. A run that
compares conditions isolates every condition from the operator's own
environment, with the candidate leaking into its own baseline named as the
sharpest confound.

The rule is prose law carried by review. The audit does not gate it, because
no scanner can decide what a given experiment's outcome depends on, and a
check may never imply more than it decides.

## Consequences

The demo arrow's claims already satisfy the rule with nothing to add, since
their tree controls everything. The first arrow whose experiment touches an
LLM inherits a ready answer for the two ways such evidence rots, a result
that cannot be re-run because nobody recorded which model answered, and a
comparison that proved nothing because the operator's environment reached
the control group. Threats sections gain a named confound to check against
whenever conditions are compared.
