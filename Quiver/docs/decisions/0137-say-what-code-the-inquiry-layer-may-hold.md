# 0137. Say what code the inquiry layer may hold

Status: Accepted
Date: 2026-11-26

## Context

The rulebook's section on code said that the inquiry layer carries no
code beyond the audit script, and the map opened with the same sentence.
The edition tool arrived later, a second script beside the audit that
the rules of adoption and of editions tell every project to carry, and
neither sentence was changed. A project built from this template read
the two together, found that the boundary taken at its word removes a
tool the delivery rules require, and asked whether the boundary means a
list of the style's tools or allows a project tooling of its own, since
it keeps a reader that checks its retained evidence beside the two.

## Options considered

- Naming the two tools and nothing more. Refused, because a list says
  what the style ships and not what the boundary is for, so the next
  tool would leave the sentence stale again and a project's own script
  would stand outside the law with no way in.
- Opening the layer to any script. Refused, because the boundary exists
  so that everything a claim rests on is computed where a suite tests
  it, and an analysis written as a script would escape that.

## Decision

The section names the style's two tools and says what the boundary is
for. Code that computes anything a claim rests on lives in an arrow. A
script that maintains the repository and computes nothing a claim rests
on may stand beside the two tools, once a decision record of the
project's own names it. The map's opening and its testing paragraph name
the edition tool, and the README's listing of the scripts folder shows
it. The paragraph was read back twice through a weaker model against six
cases, and three gaps the readings found, the record a project's script
needs, the verb the two rules share, and the reach of the first
sentence, were closed before it landed.

## Consequences

A project's maintenance script is lawful where its own record names it
and unlawful where a claim leans on what it computes, and the edition
tool no longer stands outside the sentence that governs it. No check
reads the boundary, so it stays a rule of review.
