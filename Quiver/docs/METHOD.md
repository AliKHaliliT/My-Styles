# The Method of a Pass

This file is the technique of a pass over the literature, the steps a pass runs inside the six stages the rulebook names, in the order they run, from the first seed to the screening here and from the checks to the record in [FOLD.md](FOLD.md); both are read whole before a pass begins. It is normative and frozen like the rulebook; it changes only inside the template, in the My-Styles repository and by its owner, with a decision record, and a project built from this template never edits its copy, except in the paragraphs that open with `Field binding.`, which carry the demo's field and are rewritten for the project's own field at adoption and re-adapted from a diff at each re-alignment, as the tool-configuration blocks are. Everything unmarked is law in every field. The full method is the spine every pass is measured against, and any step a pass skips is skipped in writing, in the stage line that would have carried it, which is the price the rulebook already charges for shortening the spine. A pass that names a form from the field's vocabulary, a rapid review, a mapping study, names the pattern of collapse that form is, and its stage lines say which steps ran.

## Before the search

A pass serves one slice of one question, named by number and small enough to hold in view, and the whole of its Boundary is written before any string runs, because a criterion written after the records arrive is a criterion the records wrote. The Boundary names the indexes the pass will cover, the window, the criteria, the seeds and the strings, and the record is written once, so a string corrected after a pilot is a new string in the Boundary with its own day, and a change of meaning after the search is a new pass.

Existing reviews come first. Before the criteria are written, the pass searches the slice's indexes for the reviews, surveys and mapping studies that stand near it, with a review term added to the string or the index's own filter for review articles, enters each with the window it covered and the questions it answered, and writes in the Nearest review line of its Boundary what this pass adds, a newer window, a different question, a different index or a different method, or says that no review stands near the slice. A review that already answers the slice over a recent window is the finding, and the pass narrows its slice or extends that review rather than repeating it. The reviews found are kept aside, because their reference lists seed the snowball and the completeness review.

The seeds are fixed next. Before any string runs, the pass fixes five to fifteen works known to be relevant, from the question's decomposition, the earlier passes over the slice, the reference lists of the reviews just found and the owner, each with the source it came from, and never from the string they will test, because a seed the string found proves only that the string finds what it finds. For each seed and each index the pass records whether the index holds it, by searching its title, and the seeds line counts them. Fewer than five seeds is a finding about the slice and is written in the Boundary.

The criteria are written before screening, what a record needs to pass and what excludes it, each decidable from a title and an abstract or from a full text and saying which, with a scope rule for every borderline the slice already shows and the noise the field is known for listed among the exclusion reasons before it is met. The window, the language and the document types are stated once and applied in every index alike, and no subject-area filter is set, because a subject filter drops the neighboring field's paper without saying so.

The indexes are chosen from the ones this inquiry can reach, named in the marked paragraph at the end of this file, by where Scouting found the slice's literature to live, and the Boundary says which the agent searches itself and which the owner runs. An index the field needs and the inquiry cannot reach is named in Left out with its search written out, never dropped in silence.

## The search

A string is two to four concept blocks joined with AND, each block the synonyms of one concept joined with OR, with spelling and hyphenation variants, plurals and abbreviations, phrases in quotation marks, and truncation on the stem wherever the index supports it, applied alike in every index that does and spelled out where one does not. A string searches title, abstract and keywords and never full text, because a full-text hit is a work that mentions the concept once. Each index gets the string in its own syntax, one translation per index, kept in the Boundary as run with the day it ran and its raw count, and a NOT term excludes only a documented noise pattern, added only after the seeds show it removes none of them.

The first run is a pilot. The pass reads which seeds the string returned and which it missed, and for every indexed seed it missed it reads the seed's title, abstract and keywords for the word the string lacked, fixes the string, and runs it again as a new string with its own day. It reads the noise the run returned, the false-positive patterns with two or three example titles each, and adds each pattern to the exclusion reasons. It counts the plausible includes from a quick title screen, so the depth of the pass is chosen from a number rather than from a guess. A string passes when it returns every indexed seed, or the Boundary names the seed it missed and why the pass went on.

The agent runs every index it can reach, the open ones among them, and logs each run. An index behind a license is the owner's to run, from a search the pass writes out whole, the string in the index's syntax, the filters, the window and the export to take with its abstracts; the owner runs it as written and hands the export to the pass, which checks the export's count against the run's and enters the run in the Boundary as run by the owner. A licensed search nobody ran before the pass closed is written out in Left out and queued in the state file.

Records are merged by identifier first, then by normalized title, then flagged by first author, year and the first words of the title for a person to confirm, keeping the most complete record and noting every index that returned it, with the count logged after each step. A conference version and a journal version of one study are related versions and not duplicates, and the pass cites the most complete. The funnel line counts what survived.

## Screening

Every record is screened on its title and abstract against the written criteria, with one decision and one reason per record, the reason a criterion by its label or one of the standard reasons, in the screening log the record names, so the funnel's contents are kept and not only its counts. A record that cannot be decided from its title and abstract goes to full text, and that is the only place unsure is allowed.

A decision made by one reader is a reading, and two readers who decided apart from each other are a check. The owner screens a calibration sample first, twenty to fifty records, or the whole set, and a reader who has not seen the first screen's decisions screens the same records against the same criteria, the agent in a context given the records and the criteria and nothing else; the disagreements are listed with both reasons and the owner decides each, in the log. Agreement is reported as the count the two decided alike and the list they did not, never as a coefficient, because a coefficient standing in for the list is the score the family carries none of. Where the second look is collapsed, the stage line says so, and the claims resting on the pass say the screening was one reader's.

Every record that passed is read in full where a copy can be opened, and for each criterion the passage that decides it is quoted with its page or section in the log. A work no copy of can be opened, by the agent or by the owner through a library, is decided on its abstract, entered at abstract depth, queued in the state file for a person with access, and named as a limit of the pass.

From every entered work and from the reviews kept aside, the pass reads the reference list backward and the citing works forward through an index that lists citations, screens the candidates against the same criteria, and logs each round with its start set, its candidates and its new entries, until a round adds none. A citation tracker that offers no export serves here as a tracker and never as a counted index, because it returns nothing a funnel can hold.

Where the slice's evidence lives in documentation, code, standards or practitioner writing, the pass runs a grey strand beside the academic one, with its sources and terms named before it runs, a stopping rule written in the Boundary, twenty consecutive results with nothing new or the first hundred, whichever comes first, as the default, and every source entered with its tier of standing and an archived copy named where the source can move.
