# 0055. Dispose of the eight entries of 2026-10-21 from three styles

Status: Accepted
Date: 2026-10-22

## Context

One maintainer of projects built from three of the family's styles sent
eight upstream entries as issues, the ninth to the sixteenth on the
repository, all dated 2026-10-21 and pinned at the family's a30ebbd,
which the family's history holds, and all filed as defects. Each was
tested against the template's tree at that commit before ruling. Seven
were real against the template's own law, four of them in checks the
family had landed in the week before, and one named a failure the
template's own toolchain does not show.

## Decision

- The anonymity matcher missing mounted roots and the selftests planting
  fewer address kinds than the records promised, from every style. Kept.
  The roots gain media, Volumes, private and run in every seat's audit,
  and each selftest plants an email, a drive path and two mount-root
  paths beside the URL and the home path; reading every slash-opened
  token as a path refused. The package seat's 0118, the server seat's
  0120, the client seat's 0114 and the host seat's 0113.
- A producing pin wrapped across a line break escaping the matcher, from
  the host. Kept. The matcher reads any whitespace between the arrow,
  the word at and the hash, the selftest plants a wrapped pin, and the
  claims rule says so; refusing the wrapped spelling refused. The host
  seat's 0110.
- The orphan-claim plant at a fixed number that a real question link can
  silence, from the host. Kept. The plant becomes a proof that allocates
  its number, and the reasoning of the host's record 0075 is narrowed to
  plants whose finding a collision cannot inherit. The host seat's 0109.
- The withheld-artifact rule failing through an ignored symbolic link
  and relative links, from the host. Kept. A path git refuses to judge
  is judged by the nearest ancestor git answers for, never by following
  the link, and a relative link to a withheld target is a check not run
  rather than a dead link. The host seat's 0112.
- The pass and review documents naming the exports folder as a path the
  tree must hold, from the host. Kept, as prose. The three sentences
  name the searches folder under its parent the way the screening rules
  name theirs, as a place that appears with the first pass that keeps an
  export; teaching the audit that a frozen document's token is a
  specification, and shipping the folder empty, refused. The host seat's
  0111.
- The loopback guard refusing the Unix domain socket Python 3.14's
  forkserver uses, from the package style. Kept, and widened to the
  server style and the arrow, which carry the same configuration. The
  suite allows Unix domain sockets beside the loopback, since such a
  socket names no host and never leaves the machine; the per-test mark
  and a change of start method under test refused. The package seat's
  0120 and the server seat's 0122.
- The bare-citation check reading a serialized form compared byte for
  byte as prose, from the package style. Kept, and widened to the
  family. A line that names the same record with its owner clears a bare
  mention on that line, in every seat's audit; exempting string literals
  refused. The package seat's 0119, the server seat's 0121, the client
  seat's 0115 and the host seat's 0114.
- Access-log capture failing once the application's startup quiets its
  logger, from the server style. Kept in part. The template's suite
  passes in that order under the pytest it runs under, which attaches
  its capture to a logger that does not propagate, so the development
  requirements name that floor and the suite stays as it is; the fixture
  that rebuilds the capture inside the suite refused for the template
  and left legal where the project wrote it. The server seat's 0123.

## Consequences

The projects delete the eight entries at their next re-alignment and
take the templates' forms, keeping the fixture of the last entry where
they already carry it. Four of the eight named checks the family had
landed in the week before, which is the feedback those checks were
landed to earn.
