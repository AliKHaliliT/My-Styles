## Context

## Decision

seats add pytest-socket and carry the loopback restriction in their test
configuration, so every connection that would leave the machine is refused
with the host named and a test that must reach one declares it with the
plugin's mark; the client seat's setup already refused every unhandled
request and is named as the same rule. The guides' test bullet states the
principle, the Test honesty gate item carries it, and the maps count it as
the sixth rule. The records are Keel 0071, ArchetypeCore 0068, and Helm
0072, the arrow inheriting Keel's. The draft's credential fixture was
refused, since it stops the authentication and not the request and its
variable list is one stack's.

The claim was tested before it was kept. The package style's own adapter
falls back to the environment's key, its suite constructs no such adapter
today, and the three Python suites passed unchanged under the restriction
while a probe reaching an outside host was refused by name.

deletes the entry. A suite that spawns a subprocess is bound by the sentence
there, since the restriction lives in the test process alone.
