# 0045. Dispose of five entries from a host-style project at d4b405a

Status: Accepted
Date: 2026-10-08

## Context

One project built from the host style, carrying a package arrow and a
server arrow, sent five upstream entries, one from the host at the
family's d4b405a and four from the server arrow at b8750ef, the pins
their aligned lines name and the family's history holds, while the
package arrow's file was empty. Each entry was tested against the
template's tree at its pin before ruling, and all five were real
against the template's own law.

## Decision

- The stale-pin scan watching a package's layout in every arrow, from
  the host. Kept. The scan keeps one row of paths per family style and
  reads the style from the manifest's Style line, which the audit now
  holds to a style the scan knows; a per-manifest path list and a
  fallback to the package row are refused. The host seat's 0074.
- The first generated migration failing the seat's own gate, from the
  server arrow. Kept in a stronger form. The script template renders
  the seat's shape and a post-write hook in `alembic.ini` runs ruff's
  fix over the file Alembic writes; the remembered step is refused. The
  server seat's 0092.
- Migrations running against a database the application is not
  configured with, from the server arrow. Kept whole. The Alembic
  environment reads the settings' synchronous URL, the ini names no
  URL, the helper strips the SQLite async driver too, and the suite
  holds it. The server seat's 0093.
- The backup script never removing an old database backup, from the
  server arrow. Kept. The prune groups its names before the delete; a
  ShellCheck step is declined under the every-seat rule. The server
  seat's 0094.
- The docs audit refusing an import root outside the tree, from the
  server arrow. Kept in the form that keeps the check's meaning. A root
  with no home in the tree is found on the import path without
  importing anything and its modules join the coverage comparison;
  `find_spec` on a dotted name and an in-tree-only comparison are
  refused. The package seat's 0094 and the server seat's 0095, the
  demo arrow inheriting the package seat's.

## Consequences

The project deletes the five entries at its next re-alignment, takes
the server arrow's template, hook, environment and prune, and may write
the contract it dropped, naming the engine's portions as roots.
