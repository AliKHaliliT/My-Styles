# 0073. Dispose of six entries from a server-style project at 777ea6f

Status: Accepted
Date: 2026-11-25

## Context

One project built from the server style, with a client from the client
style kept in a folder of it, holds six upstream entries, three in each
of its upstream files, dated 2026-11-24 and 2026-11-25 and pinned at the
family's 777ea6f, which the family's history holds. The style's owner
asked for all six resolved and landed. Tested at the pin and at the
family's 05a5f80, all six were real, and one reached further than it
said.

## Decision

- A value a request validator refuses is answered with a 500. Kept in
  the entry's form. The server seat's 0147.
- The reorder decorator drops a schema's bases. Kept and widened, since
  the rebuild also dropped the bases' methods, every validator and
  configuration built into the schema, and its read of a class's
  annotations raised under Python 3.14 for a forward reference. The
  decorator now reorders the class in place. The server seat's 0148.
- The tooling does not see an engine's suites and ports. Kept in the
  entry's form, and the shared Python audit's seams check now reads
  every folder named tests. The server seat's 0149 and the package
  seat's 0139.
- The request door cannot send a PUT. Kept in the entry's form. The
  client seat's 0139.
- The request door takes no abort signal. Kept as an improvement. The
  client seat's 0140.
- A field's error joins its accessible name. Kept for the text field,
  since the template's kit has no select field. The client seat's 0141.

## Options considered

- Holding the engines' tooling in the adoption rehearsal's shaped child.
  Refused, because the rehearsal gates a child by its docs audit and its
  selftest alone, so it could hold the seams check and not the suite run
  or the lint.

## Consequences

The project deletes the six entries at its next re-alignment and takes
the template's fixes. The guards it wrote against a decorated schema
itself keep working, and a decorated schema now passes a guard against
any of its bases as well.
