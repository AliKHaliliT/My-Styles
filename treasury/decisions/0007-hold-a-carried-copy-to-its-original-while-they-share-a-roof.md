# 0007. Hold a carried copy to its original while they share a roof

Status: Accepted
Date: 2026-08-28

## Context

Quiver's record 0005 made every arrow a full adaptation of its style, and the
demo arrow took the promotion literally, carrying Keel's rulebook, baseline,
docs audit, dotfiles, inert workflow, inherited decision records, and the
shared tail of the agent guide as verbatim bytes. Nothing gated those copies.
The day Keel amends its rulebook or writes its next record, the exemplar
arrow drifts silently, and the exemplar teaches whatever shape it has. The
family already refuses exactly this rot between the styles, where
`scripts/audit_family.py` holds the peer blocks to one text, so the carried
copies were the one replication in the repository still guarded by memory
alone. The instrument was observed working in the wild, in the public
repository ayghri/i-have-adhd, whose CI runs a byte comparison between its
canonical skill file and the mirror another editor reads, and fails on
drift.

The owner set the boundary of the rule when adopting it. Inside this
repository the copy tracks the original. An instance created out of this
repository freezes at extraction, owes its style nothing afterward, and
adapts to later revisions only through its own owner's deliberate
refactoring. Nothing an arrow carries may depend on a tracking mechanism or
teach an agent to expect one.

## Options considered

- Gating inside Quiver's own audit was rejected. The inquiry audit rides into
  every instantiated inquiry, where the style is not present at all, so the
  check would break the day the seat is used for real, and its presence in
  the arrow's world is exactly the tracking dependency the owner forbade.
- A sync script that rewrites the copy from the original was rejected.
  Detection is the gate's whole duty; rewriting law is a reviewed edit, and a
  tool that performs it unattended is a machine deciding what an agent may
  not.
- Freezing the demo arrow at transplant was rejected for the same reason
  record 0005 refused a trimmed exemplar, since a stale exemplar teaches
  stale law.

## Decision

`scripts/audit_family.py` gains a second duty beside the peer blocks. A
manifest of carried copies names each original and its copy, whole files or
an anchored tail, and a divergence fails the audit with the original named
as canonical, so the fix is always rewriting the copy. A second manifest
names inherited record folders, where every record of the original must
exist in the copy byte-identically while the copy may add records of its
own, because a full adaptation records its own decisions in its own
sequence.

The gate lives at the host root only. No arrow carries the script, no
extraction copies it, and the freeze at extraction therefore needs no
mechanism at all, it is what remains when the tracking stays behind.

## Consequences

A change to anything Keel that coinwise carries now turns CI red until the
arrow catches up in the same change, which is the transplant rule of
Quiver's record 0003 extended from birth to every day after. If Keel and an
arrow ever claim the same record number for different texts, the audit
reports the divergence and a person resolves the collision. The manifest is
also the blueprint, as with the peer blocks. When a new arrow or a new style
joins, listing its carried files is what puts them under guard.
