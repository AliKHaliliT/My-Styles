# 0051. Let a branch carry up to five prose-only rules

Status: Accepted
Date: 2026-10-17

## Context

The family's conduct rules land a change through one branch merged with
main, gated whole, pushed, run and fast-forwarded, and every change to
the law had landed alone. A series of ten short rules, each a paragraph
of prose in every seat, paid the whole cycle ten times, most of it
waiting on the remote, while no one of them could break a check.

## Decision

Each rule is one commit with its own record. A branch carries one such
commit, or up to five when every one of them changes prose alone, no
check, no code and no tooling among them, and the branch is gated whole
and pushed once; a change that touches a check or code travels alone,
and one branch at a time stands. Keeping one landing per rule and
letting a branch carry commits of any kind were refused. The package
seat's 0116, the server seat's 0118, the client seat's 0112 and the host
seat's 0105.

## Consequences

A run of short rules lands in one cycle, history and the records stay
one to one, and a red run over a prose branch points at five paragraphs
at most.
