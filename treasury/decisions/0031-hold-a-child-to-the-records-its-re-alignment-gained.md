# 0031. Hold a child to the records its re-alignment gained

Status: Accepted
Date: 2026-09-17

## Context

The owner asked whether re-alignment says what alignment means, suspecting
that a child fetches the latest law, fixes what a check turns red, and never
minds the rules held in review. The guides were read first, and their text
predicted the behaviour, because re-alignment asks the child to read the
records gained and run the gate, gives a dropped rule a tree-walking step
and a gate item, and gives a gained rule one verb. Then a child was
measured.

## Evidence

One project built from the host style, with three arrows under three of the
family's styles, read by its history on 2026-09-17 and written to nowhere.
Six alignment commits between 2026-09-07 and 2026-09-10 and one partial
adoption on 2026-09-17.

| Rule | Form | Held |
| --- | --- | --- |
| Inherited folder whole and byte-identical | audit check | yes |
| Own decisions folder holds own decisions and nothing else | rulebook prose, gained 2026-09-09 | no, twenty-two template records under the project's numbers, the commit body claiming otherwise |
| Clause-colon splice banned | hard rule, review | no, about three in four of a random forty candidate lines |
| Em dash budget of two per file | workflow count | no, ten files over, the project having no remote so the workflow never ran |
| Every badge states something true | README rule, review | no, a test count eleven days stale through two edits of the file |
| Both-paths test rule | review, gained 2026-09-09 | engaged, with a record saying why the tolerance half had no subject |
| Supersession and the Recorded line | review and advisory, gained 2026-09-09 | applied, on the project's own upstream entries the template had taken |
| README content contracts | review, gained 2026-09-09 | not re-read, the file changed by the pin sentence alone |

The older children under the client style, dormant since 2026-08-19 and
aligned under the earlier procedure, show the same shape in their alignment
commits, carried files plus whatever a new check turned red, one body saying
outright that the new checks earned their keep on the first run. No child
but the measured one carries an upstream pin, so nothing further was read.

## Options considered

- Rewording the re-alignment paragraph alone. Refused under the ladder,
  because the sentence that says read was already there and bound nothing;
  the enumerable half, which records were gained and whether each is cited,
  can be checked.
- A check that a gained rule changed the tree. Refused, because a rule that
  binds nothing in a tree is a legal outcome.
- Moving every workflow step into the audits. Refused beyond the gating
  count, because the spelling and vocabulary steps advise and need tools the
  audits do not carry; the em dash budget gates and needs nothing.
- Ruling on a repository with no remote. Left open, because the branch
  protocol assumes a run to wait on and the family has not decided what a
  landing is where none exists; the owner decides.

## Decision

Three law changes, each its own landing, each recorded in every seat with
the arrow inheriting the package style's record. A re-alignment writes one
decision record of the child's own that links every record the inherited
folder gained and says what each did to the tree, and the docs audit holds
that no gained record goes uncited, binding from its scope sentence and
exempting the folder's first arrival. The docs audit fails a record in the
project's own decisions folder whose body, beyond its heading and status
line, is an inherited record's, so a template record kept under the
project's number goes red. The em dash budget moves from the workflow into
the docs audit of every seat, so a project with no remote still counts it,
and the inert workflows lose the step while the family's own root workflow
keeps it for the files no seat audits. What holds in a child is what goes
red in the worker's terminal, and each change puts a rule there.

## Consequences

The next re-alignment of any child under the new law costs one record per
seat and turns up every template record it kept under its own numbers and
every file over the em dash budget. The measured behaviour stays on record
here, nameless, as the reason the three rules exist. The review-held rules
the measurement found broken beyond these three, the colon splice and the
badge, stay review's, and the finding that they are not held in a child is
the owner's to take further.
