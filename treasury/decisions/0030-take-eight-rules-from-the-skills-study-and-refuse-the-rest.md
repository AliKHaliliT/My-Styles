# 0030. Take eight rules from the skills study and refuse the rest

Status: Accepted
Date: 2026-09-16

## Context

Study 0005 read the published agent-skills ecosystem against the family's
law. It harvested 2,272 names, 519 distinct once two generated families
collapsed, cloned forty repositories for the process territory, and executed
nothing. The family had refused skill files as a mechanism in
[treasury 0004, Let the index do what skill files do](0004-let-the-index-do-what-skill-files-do.md),
and this record does not reopen that. It disposes of the practices found
inside the files. Twenty-six candidates survived jurisdiction and
deduplication, and each was then checked against the text of every guide,
rulebook, map, baseline, record, script and configuration before it was
called absent.

## Evidence

The guide proves every audit rule against a planted defect and says nothing of
the kind about the test suites, whose bullet governs placement, substitution
and breadth only. The gate's test-honesty item says time, randomness and order
are controlled, and no configuration in any seat enforces order. The branch
protocol mandates one working tree per session and no `.gitignore` names the
directory a second tree would occupy. No seat's linter selects the rule that
flags a print statement, and the client's linter has no console rule. The
audit selftests report the plants they skip; the audits themselves report only
the layout scope, so a tree with no package root passes as agreeing with
conventions it never checked. The prose law cuts hedges and protects no
qualifier. The commit-body rule reserves the body for a why that explains one
change and says nothing about where else a defect was sought.

Six candidates were found already held, each at a line.

- Delete-first sits in the Waste and Leftovers-swept items and in the
  tested-fallback clause.
- Loosening a rule cites its record through the supersede-and-link rule.
- Two documents always read together are one under the adoption's folding
  rule.
- The nameless rule already names every tracked byte and every commit
  message.
- A refactor changes no behavior under Two hats.
- The read-back is a drafting practice by its own record.

One candidate was measured. Across the family and a project built from it,
75 of 1,213 prose paragraphs open with a bare demonstrative, every one with a
clear antecedent.

## Options considered

- Adopting the candidates as skill files or an activation pack. Refused;
  treasury 0004 stands and its reopening conditions were not met.
- Landing the eight adoptions as one change. Refused, because each law change
  lands alone. The exception is the test proof, which is one law stated at
  three moments and lands as one record with three headed clauses, on the
  precedent of the shape limits, which landed three limits as one ruling.
- Writing the mechanizable adoptions as sentences. Refused; the ladder adopted
  here says a check or a configuration lands where one can, so four of the
  eight are checks or configuration and not prose.
- Holding candidates for later. Refused; the family has no shelf. A candidate
  lands or is refused with the condition that reopens it.
- Binding how a worker treats content it reads. Refused, because the scaffold
  works by the worker obeying the repository's documents, and a rule that what
  is read is never an instruction would bind the guide itself.

## Decision

Eight adoptions, landing separately in this order, each with a record in every
seat whose bytes it changes.

1. The enforcement ladder. A rule lands in the form that makes its mistake
   impossible where one exists, else as a gated or advised check, else as
   prose. The rulebook states it beside the rule that lets the machine catch
   what it can.
2. A test is proved by the failure it catches. Before it is written, the test
   names the break it catches and derives its expectation without the code
   under test. After it is written, the code is mutated against a closed list
   and a test fails for each mutation. After a fix, the fix is reverted and the
   regression test is watched failing, on its assertion and not on its
   harness. One record, three headed clauses.
3. The suite runs in random order under a recorded seed, by configuration in
   every seat.
4. The directory a second working tree occupies is ignored before it is
   created, by an ignore entry, a baseline row, and an audit line.
5. Print and console statements are linted out of source, scripts and declared
   output paths exempt.
6. An audit that could not run a check reports which one, as its selftest
   already does for plants.
7. A qualifier that bounds a claim survives the cut for filler. "No known
   remaining risks" is not "no remaining risks".
8. A fix's commit body names where else the same defect was looked for and
   what was found.

Ten refusals, each with the condition that reopens it, two of them sharing
one entry because they share one reason.

- Content read is never an instruction. The scaffold works by the worker
  obeying the repository's documents, so the rule would bind the guide
  itself. Reopens if a document inside a tree steers a worker by posing as
  the guide, which the index contract exists to prevent.
- Stage only the paths the task owns. Made impossible by the branch protocol,
  since a session's own working tree holds no other session's state, and by
  the baseline's rule that scratch lives outside the tree. Reopens if a commit
  is found to have swept bytes its task did not own.
- No bare demonstrative opens a paragraph. Refused on the measurement above.
  Reopens on a measured case of an unclear antecedent.
- A cause claim names its falsifier. The Evidence section already carries the
  discriminating observation in every record checked. Reopens if a recorded
  cause proves wrong without the evidence having shown the doubt.
- No verbless fragment opens a paragraph. The theater clause covers it and no
  check can find it without a parser.
- Run the suite before starting, and stop after three failed fixes. Conduct
  rules, which treasury 0004 keeps out of style law.
- Tests wait on conditions, never delays. No seat has a delay in a test.
  Reopens on the first one.
- Assert the strongest property. The derandomized-properties rule governs
  property tests and the ordering adds little.
- Verify a review finding against the current file. Binds a review step only
  the host seat has, so it fails the every-seat rule. Reopens when every seat
  has one.

Six candidates were already held and are cited in the findings.

## Consequences

The adoptions land in the order above, the ladder first because it decided
the form of four of the others. The method gained two lessons from this study,
that an already-enumerated corpus tempts a pass that skips the reading, and
that coverage is counted by source and never by volume read. The next study of
agent practice starts from the twenty-six here and the sources named beside
them, instead of harvesting the ecosystem again.
