# 0043. Dispose of five entries from a host-style project at d4b01e1

Status: Accepted
Date: 2026-10-05

## Context

One project built from the host style, carrying an arrow of the package
style, sent the upstream files of its host and that arrow, five entries
dated 2026-10-03 and 2026-10-04, every one pinned at the family's d4b01e1,
which their aligned lines name and the family's history holds. Every
entry was tested against the template's tree at that commit before
ruling, and four of the five were real against the template's own bytes.

## Decision

- The module-mocking grep absent from the workflow a project inherits,
  from the package arrow. Kept. The package, server and client seats run
  the Seams step in their own workflows with the root's grep and message,
  the demo arrow carries the package seat's, and every ledger gains the
  row the step holds. The package seat's 0087, the server seat's 0085
  and the client seat's 0088.
- Mirrored suite names colliding under the runner's default import mode
  and the type checker's discovery, from the package arrow. Kept,
  reproduced with two planted suites. The three Python seats import a
  suite by its path, and the package seat and the demo arrow give the
  checker the source root as its explicit package base. The project's
  naming workaround is refused. The package seat's 0088 and the server
  seat's 0086.
- A required class docstring reaching a language model through the
  schema generated from a pydantic model, from the package arrow. Not a
  defect of the template, whose translator sends a hand-built schema,
  and kept as one sentence of the docstring convention in the two Python
  seats, with the exemption the project named refused. The package
  seat's 0091 and the server seat's 0089.
- The splice advisory counting a list marker as a word, from the host.
  Kept. The four implementations drop the marker before counting, and
  every selftest plants the two cases. The package seat's 0089, the
  server seat's 0087, the client seat's 0089 and the host seat's 0070.
- The demo arrow's experiment listing an exception it never raises, from
  the host. Kept, and found twice more in the template's own code. The
  three docstrings write the sentinel, and the docs audit of the Python
  seats holds a Raises section to the raise statements in the body. The
  package seat's 0090 and the server seat's 0088.

## Consequences

The project deletes the five entries at its next re-alignment, takes the
workflow step, the import mode and the checker's base with the
configuration, names the two suites it had renamed after their units
again, keeps or drops its schema suppression under the new sentence, and
meets the Raises check wherever an experiment cut from the exemplar
listed a callee's exception.
