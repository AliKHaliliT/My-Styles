# 0013. Dispose of the ARCS project's upstream report

Status: Accepted
Date: 2026-09-07

## Context

An inquiry project named ARCS, a Quiver instance carrying three arrows in
the Keel, ArchetypeCore, and Helm styles and aligned at commit 2b38e75, sent
five entries with the records it had read named per entry. Each was tested
on the family's own trees before disposition, and two arrived with the
wrong account of how the template behaves.

## Decision

- Adapted: the phantom bibliography entry. The rulebook and a record write
  the example key in backticks and the citation check could not tell a
  code span from prose. Neither proposed fix was taken; a key inside
  backticks is a mention of the form, and the audit blanks code spans
  before reading citations.
- Kept: the two selftest plants written against the demo. A plant now
  builds whatever it names, a temporary arrow and manifest, a planted
  bibliography entry, and every demo name left the script.
- Kept, diagnosis corrected: the deprecated 422 constant. The template's
  suite does not turn red, because nothing in it imported the application;
  a child's suite does. The rename landed with a suite that boots the
  application under the warnings gate, its first named dependency ignore,
  and the test client's dependency.
- Kept, description corrected: the render helper. The template's pages had
  no tests at all rather than tests through prop-taking components. The
  helper mounts a route when given one, and the vessel detail page gained
  its suite at an address.
- Kept: the error field. The client reads `detail`, then `message`, then
  `title`, and the demo's mock backend now refuses in the server's
  envelope, so the primary path runs in the demo.

The report's container, a dated file with numbered entries and labeled
parts, was the closest of the four received to what the family's own record
rules produce, and ruling 0015 fixed that shape for every child.

## Consequences

The project reverts its local bibliography entry for the standard, its
private workaround for the render helper, and its private reading of the
error body, and re-aligns to the commit that carries this record.
