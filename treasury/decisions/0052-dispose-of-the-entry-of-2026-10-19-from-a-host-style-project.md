## Context

One project built from the host style sent one upstream entry as an
issue, the sixth on the repository, pinned at the family's 2842b6c,
which the family's history holds. The entry was tested against the
template's tree at that commit before ruling, and it was real against

## Decision

- An artifact a `Recorded:` line names and a license keeps out of the
  tree, from the host. Kept, and widened by one step the entry did not
  ask for. The verdict is whether the tree holds the artifact, asked of
  the index, so a file never added fails in every checkout alike; an
  artifact the ignore file names is withheld by declaration, no verdict
  either way, and the audit names it on every run as a check not run

  and a pass record's Boundary alike. Keeping existence as the verdict,
  superseding the claims and a new word on the immutable line were

## Consequences

reports where they lie under the path its ignore file already names; its
claims stand unedited and every checkout reads the same line about them.
