# 0103. Read a document whole before relying on it

Status: Accepted
Date: 2026-10-09

## Context

The guide's index says when each document is read, the state file is
read first and the rulebook before any documentation is written, and
nothing anywhere says how a document is read. A model reads a file the
way its tools and its habits let it, the first lines and the last, or
a slice from the middle, and a rule that sits in the part it skipped is
a rule it breaks without knowing. The index that names every document
is the last section of the guide, so a reader who takes the first lines
and the last never meets the rules between them. The owner raised it on
2026-10-09 as one of the reasons the family exists.

## Evidence

Measured on 2026-10-09. The guides run from 161 to 170 lines and from
6,262 to 6,947 words, a line being a whole paragraph, and the rulebooks
from 4,908 to 6,492 words; the 150-line budget binds only the bounded
living documents and counts lines, so it says nothing about what a
reader of the guide takes in. No sentence in any guide or rulebook asks
for a whole read.

## Options considered

- A check that a document was read. Refused, because no tool can see a
  reading; the strongest form left is a sentence in the one place every
  reader passes, the guide's first paragraph.
- Asking the closing note to name the documents read whole. Refused,
  because a self-report costs nothing to write and proves nothing, and
  the family cuts that kind of theater.

## Decision

The guide's first paragraph says that this guide is read to its end
before any work, and so are the rulebook, the state file, the map, the
ledger and the baseline where the work touches what they govern, that a
document is read whole and never by its first and last lines, and that
the index at the end names every other document and when it is read. A
hard rule says the same for every document the index names, first line
to last before it is relied on, with code read as the task needs and a
record read whole when it is cited. The size of what must be read whole
is the next question, and a measure of it is its own record.

## Consequences

A reader who follows the first paragraph meets every rule between it
and the index, and a reader who does not has broken a rule it was told
of in the first lines it read.
