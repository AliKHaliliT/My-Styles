# 0094. Leave the sending of an entry to the owner

Status: Accepted
Date: 2026-10-09

## Context

The upstream block told the style's owner to read a project's file and
point an agent at the template, and told anyone else holding the file
that the right move was to file each entry as an issue on the
template's repository. It named no actor for the filing and no gate
before it, so an agent working in a project that is not the style's
owner read itself as anyone else, and nothing in the law stopped it
from filing an entry on a public repository on its own, with whatever
the entry carried. The first entries to arrive as issues, on
2026-10-08, were sent by a person; the sentence did not require that.

## Evidence

Measured on 2026-10-09. The sentence stood in the shared upstream block
of the four guides and in the demo arrow's carried copy, and no hard
rule bound an agent's acts outside the repository; the pause rule binds
a worker that a check fights, not a worker about to send. The family's
own repository is public, so an entry filed there is public the moment
it is sent.

## Options considered

- Forbidding the issue channel. Refused, because an open template's
  feedback has nowhere better to go, and the channel is not the leak;
  the unnamed actor is.
- A check that catches an entry being sent. Refused, because the audit
  reads the tree and a sending is not in the tree; the strongest form
  available is a sentence with the owner's gate, in the shape the pause
  rule already gives a worker.

## Decision

The project's owner files an entry as an issue on the template's
repository. An agent never sends an entry, or anything else, outside
the repository on its own, not as an issue, a message, a pull request
or an upload, because what leaves the repository cannot be taken back;
it proposes the sending in its closing note as a numbered option and
the owner sends or declines. The upstream block says so for entries and
a hard rule says so for every outward act, in every guide, the demo
arrow carrying the package seat's.

## Consequences

An entry leaves a project only by its owner's hand, and an agent that
finds something worth sending has a form for saying so that costs it
nothing and the owner one word.
